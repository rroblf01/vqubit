# Ejemplo: importar y exportar circuitos

Un circuito no tiene por qué nacer en Python: puede venir de un fichero
OpenQASM, de un enlace de [Quirk](https://algassert.com/quirk) o de un documento
JSON que guardó otro programa. Este ejemplo recorre los tres formatos, en los
dos sentidos.

## OpenQASM 2.0

`vq.qasm` escribe el circuito y `vq.circuit_from_qasm` lo lee. El importador no
necesita `ply` ni ninguna otra dependencia:

```python
import vqubit as vq

q0, q1 = vq.LineQubit.range(2)
circuit = vq.Circuit(vq.H(q0), vq.CNOT(q0, q1), vq.measure(q0, q1, key="m"))
print(vq.qasm(circuit))
```

```qasm
// Generated by vqubit
OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
creg m[2];
h q[0];
cx q[0],q[1];
measure q[0] -> m[0];
measure q[1] -> m[1];
```

Y de vuelta:

```python
restored = vq.circuit_from_qasm(vq.qasm(circuit))
print(restored == circuit)   # True
```

También puedes escribir el QASM a mano. El importador entiende el juego `qelib1`
completo (`h`, `x`, `y`, `z`, `s`, `sdg`, `t`, `tdg`, `rx`, `ry`, `rz`, `cx`,
`cy`, `cz`, `ch`, `swap`, `ccx`, `cswap`, `id`, `u1`, `u2`, `u3`), expresiones
con `pi`, puertas definidas con `gate`, `reset`, `barrier` y condiciones
`if(c==N)`:

```python
hand_written = """OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
creg c[2];
h q[0];
cx q[0],q[1];
measure q[0] -> c[0];
measure q[1] -> c[1];
"""
imported = vq.circuit_from_qasm(hand_written)
print(imported)
print(vq.Simulator(seed=3).run(imported, repetitions=4).measurements)
```

```text
0: ───H───@───M───
          │   │
1: ───────X───M───
{'c': [[0, 0], [0, 0], [1, 1], [1, 1]]}
```

Las dos medidas salen correlacionadas: es el estado de Bell.

## Quirk

```python
url = vq.quirk_url(circuit)
print(url)
print(vq.quirk_url_to_circuit(url))
```

```text
https://algassert.com/quirk#circuit=eyJjb2xzIjpbWyJIIiwxXSxbIlx1MjAyMiIsIlgiXSxbIk1lYXN1cmUiLCJNZWFzdXJlIl1dLCJxdWJpdHMiOlsicTAiLCJxMSJdfQ
q0: ───H───@───M───
           │   │
q1: ───────X───M───
```

El enlace codifica el JSON de Quirk en base64; puedes abrirlo en el navegador
para ver el circuito. `vq.quirk_json_to_circuit` acepta el JSON directamente si
lo tienes guardado.

## JSON

El formato JSON es el de Cirq, así que sirve para intercambiar circuitos con
otros programas (y con la propia Cirq, si la tienes instalada):

```python
document = vq.to_json(circuit)
print(vq.read_json(document) == circuit)   # True
```

Para pasar un circuito a Cirq y volver, usa el puente opcional:

```python
import importlib.util

if importlib.util.find_spec("cirq") is not None:
    cirq_circuit = vq.to_cirq(circuit)   # un cirq.Circuit
    back = vq.from_cirq(cirq_circuit)    # otra vez vqubit
```

## Qué has aprendido

- **QASM** es el formato de intercambio más portable, y el importador de vqubit
  no tiene dependencias.
- **Quirk** sirve para compartir un circuito como enlace web.
- **JSON** es el formato de Cirq: conserva tipos, parámetros y medidas, y es la
  base del puente `to_cirq`/`from_cirq`.

Los detalles de cada formato están en [Serialización](../guide/serialization.md).
